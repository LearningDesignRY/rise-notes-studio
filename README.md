# Rise Notes Studio

I want to create a tool that allows me to create a set of static notes based on an interactive Rise lesson. The source document will be the PDF conversion, so the tool will need to read the PDF and be able to format the document using our brand conventions and iconography, and replicate the layout so that it approximates the Rise build, while obviously keeping in mind this is a static version. So in other words, where there are online interactions, the static version should adapt this (for example, if it's a set of flashcards, this is rebuilt as a tabulated information, etc). Are you the right app to do this? How would I go about building this or providing parameters to accomplish this?
